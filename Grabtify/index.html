    About

    Grabtify is a DaVinci Resolve Workflow Integration plugin for Windows. Paste a link, it downloads the clip with yt-dlp, optionally trims it, and drops it onto your timeline.

    Version Grabtify v1.0
    Created by Pedro Gottardi
    Website gottardi.vercel.app →
    GitHub github.com/pedrogottardi/grabtify →

    Fetch only videos you own or are licensed to download. Most platforms' terms restrict downloading, and this tool does not bypass DRM.
